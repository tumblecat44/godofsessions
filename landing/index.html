FAQ

Short answers before bedtime.

Is this another coding agent?

No. It reads and coordinates the agents you already use. Codex, Claude Code, and Hermes still own execution and provider receipts.

Does it act without asking?

No. Recommendations and preflight are read-only. The frozen night plan requires an exact, expiring approval.

Does all data stay local?

The control plane stays local. Prompts and execution still use the provider route you choose, under that provider's data terms.

Does Morning Review prove the code is correct?

No. It proves which provider run produced the receipt and what workspace changes were observed. You review correctness.
