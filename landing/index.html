FAQ

Short answers before bedtime.

Is this another coding agent?

No. Morrow coordinates Codex, Claude Code, Grok Build, Cursor, Pi Agent, Hermes, and OpenClaw as one overnight plan. Each selected AI tool still provides its own run receipt.

Does it act without asking?

You choose the recommended items first. Only the exact plan you approve once can run, and that approval expires.

What leaves this Mac?

Conversation history, approvals, and run status are stored in this Mac's app data. Inputs needed for answers and work are sent to the selected AI service under that service's data terms.

Does Morning Review prove the code is correct?

Morning Review separates each agent's receipt, verification, remaining risk, and failed or unfinished work. You review correctness.
