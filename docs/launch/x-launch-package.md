## Five launch FAQs

### Is this another coding agent?

No. It coordinates the agents and subscriptions you already use. Provider
tools still own execution and receipts.

### Does it run work without asking?

No. Discovery, recommendation, and preflight are read-only. A frozen overnight
plan requires an exact, expiring approval.

### Does everything stay local?

The control plane and app-owned records are local-first. Model prompts still
follow the selected provider's route and data terms.

### Does it execute all six sources?

No. It discovers six sources. Approved execution is currently enabled for
Codex, Claude, and Hermes; Grok can be routed through an approved Hermes goal.

### Does Morning Review prove the code is correct?

No. It proves which provider run produced a receipt and what bounded workspace
changes were observed. The operator still reviews correctness.
