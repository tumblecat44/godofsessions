# Overnight M12 — Codex app-server safety preflight

M12 proves the second execution route without enabling it.

## Why app-server

God of Sessions is a rich local control surface, not a one-shot CI script.
Codex app-server exposes the native thread, turn, item, approval, and streamed
completion lifecycle needed for exact dispatch and durable receipts. The
installed Codex version can generate its own JSON Schema, so the adapter can be
verified against the binary it will actually launch.

The adapter uses the executable bundled in the ChatGPT desktop app when it is
available. This avoids trusting a stale or broken package-manager shim.

## Delivered

- Stable-capability `initialize` plus the required `initialized` notification.
- A read-only `model/list` probe with a six-second fail-closed deadline.
- Version-matched live acceptance against the installed Codex 0.145 app-server.
- Read-only identity checks for the proposed existing thread:
  - exact native thread id
  - canonical cwd equal to the approved workspace
  - not archived
  - no activity in the provider log during the last five minutes
- Exact Protocol Transaction preview:
  - `initialize`
  - `initialized`
  - `thread/resume` or `thread/start`
  - `turn/start`
- One canonical Git root as the only writable root.
- `workspaceWrite` with command network disabled.
- `approvalPolicy: "never"` so a request outside the fixed boundary fails
  instead of waiting for an unattended approval.
- External execution environments disabled for the turn.
- The contract fingerprint is supplied as `clientUserMessageId`, which Codex
  persists as the user-message `clientId` and can therefore support ambiguous
  start recovery.

## Current gate

The preflight intentionally includes a blocking `adapter_wiring` check.
`dispatch_supported` remains false for Codex. No Codex thread is created or
resumed, and no turn starts from this milestone.

That block can be removed only after one-time approval consumption, request
handling, turn timeout/interrupt, item capture, terminal receipt parsing, and
client-message-id recovery are implemented and tested.
