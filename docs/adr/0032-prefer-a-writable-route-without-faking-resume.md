# Prefer a writable route without faking resume

After route health, prefer an execution route for which this build can produce
an approval-gated dispatch over a feasibility-only route. Then prefer native
continuity or configured Hermes convenience.

Own the dispatch-support predicate in the Night Contract module and reuse it
during recommendation.

A provider session may contribute evidence without being the execution
session. Set `resume_existing` and carry `native_session_id` only when the
selected execution surface is that provider's native surface. When Hermes uses
bounded context from another provider, call it a new goal and expose the
context-bridge risk.

Do not model Hermes' bundled Codex input skill as a single-capacity route. It
requires a future composite contract that freezes and revalidates both the
Hermes model Capacity Pool and the Codex Capacity Pool.
