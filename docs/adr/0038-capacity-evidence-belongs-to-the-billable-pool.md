# Capacity evidence belongs to the billable pool

Resolve execution-route readiness from its `CapacityPool`, not from its model
provider.

The same provider family can be paid through a ChatGPT subscription or
separate API credits. Evidence for one must never authorize the other.
Unobserved API credits remain degraded and approval-blocked until a dedicated
adapter can observe them.

Recommendation confidence additionally requires the exact route and run shape
to be dispatchable. Provider quota alone is not evidence that a task can
start.
